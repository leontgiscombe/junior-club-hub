Team & Subs

Backup & Restore

Your team's data syncs to the club database (stored encrypted). Exporting a backup is still a good idea before big changes. Note: the exported file itself is not password-protected, so store and share it securely.

Monthly Reminders

Get a push notification on the 1st of each month reminding you to check this team's subs and chase anyone who hasn't paid. Turn it on for each device (phone) you want reminded.

On iPhone/iPad you must first add this app to your Home Screen (Share → Add to Home Screen) and open it from there, then turn on reminders.

Security & Sync

Each team's data is encrypted in your browser with the team password before it is saved to the club database, so only someone with the password can read it. Changes sync automatically across devices. You can change this team's password below — it updates for everyone on their next login. If the password is ever forgotten, a coach can reset it in Coach Admin → Settings with the team's recovery code.

About & Privacy

This tracker holds children's and parents' personal details. It is encrypted with your admin password and stays only on this device/browser. Keep the device secure, only record what you need, and delete a player's record when they leave the team. Share backups securely.
